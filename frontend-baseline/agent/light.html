Pattern 24 of 24: agent-ready UI

Describe yourself

Three audiences read this page: people, agents that browse through the accessibility tree, and agents that call functions. One form serves all three. It is a plain GET form, so its URL is its API; the structured data in the head declares the same search in schema.org terms, which crawlers have read for a decade; and a ten-line script registers it as a WebMCP tool where document.modelContext exists, and does nothing where it does not.

Submits to /dynamic/heavy.html?q=…; the posts app turns the query into its route.

WebMCP in this browser: checking.

What each audience sees

  • People: a search box.
  • Accessibility-tree agents: a search landmark with a labelled text input and a submit button; no script needed.
  • Structured-data agents: a SearchAction with a URL template in the JSON-LD block.
  • Function-calling agents: a search_posts tool with a JSON schema, registered through src/lib/agent.js.
