Pattern 11 of 23: composite widgets

Custom widgets

The widgets component libraries exist for, written against the ARIA authoring patterns: roving tabindex, aria-activedescendant, typeahead, focus return, outside-click dismissal. Headless libraries (Radix, React Aria, Headless UI, Ark, Melt, Kobalte) package exactly this.

Tabs

React, Vue, Svelte, Solid, Preact, Lit and Angular render components; most need a router and a data layer added.

Next.js, Nuxt, SvelteKit, React Router, TanStack Start, Astro and Analog add routing, data loading, rendering modes and a server.

htmx, Alpine.js and web components take a different shape: the server renders, the browser sprinkles.

Arrow keys move between tabs and activate them; Home and End jump.
