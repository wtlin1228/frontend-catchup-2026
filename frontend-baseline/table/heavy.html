Pattern 10 of 23: data grid

Grid

Rows are generated in a Web Worker. Only the rows in view exist in the DOM. Sorting and filtering run in the worker or, for comparison, on the main thread, where you can feel the difference while typing. Rows can be selected with the mouse or keyboard and exported as CSV.

Sort and filter on

No rows selected. Click selects, shift-click extends, arrow keys move, space toggles.
