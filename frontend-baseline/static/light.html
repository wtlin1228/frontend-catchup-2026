Pattern 1 of 23: static content

About this project

This page is the floor. A heading, a few paragraphs, one responsive image, shared header and footer, and nothing else. It should cost a framework nothing. If it costs 40 KB of JavaScript, that is the first finding.

What the page contains

  • Semantic HTML with a skip link, landmark regions and a document outline.
  • The shared header and footer, included at build time from src/partials/.
  • One image with srcset, sizes and intrinsic dimensions.
  • The global stylesheet and a self-hosted font. No page-level CSS or JavaScript.

What to compare

Build output for this one page: bytes of HTML, CSS and JavaScript, and whether the framework renders it at build time, on request, or in the browser. Then open it with scripts disabled. Then run Lighthouse on it. The heavy variant is the same pattern at document scale.
