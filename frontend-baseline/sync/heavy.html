Pattern 17 of 23: sync and local-first

Notes with versions and peers

Every note carries a server version. A push with a stale base version is rejected as a conflict and you choose which text wins. Other devices show up live through a change feed. Try it: go offline, edit the first note, press the other-device button, go online. Your push conflicts; the feed brings their edit. Offline means the network, not DevTools' Offline toggle: that blocks the other-device request as well, so press its button from a second tab.
