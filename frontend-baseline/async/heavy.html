Pattern 14 of 23: async consistency

Composed view

One screen built from three sources: the post, related posts (which depend on the post) and a status call that fails half the time. Atomic mode waits for everything and paints once, so the screen never shows a mix of old and new data. Stream mode paints each part as it lands. Changing the post mid-flight drops stale responses; a failed source retries alone; likes apply in an optimistic lane and roll back when the server refuses.
