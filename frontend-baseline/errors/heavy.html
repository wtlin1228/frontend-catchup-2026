Pattern 20 of 23: error boundaries

Boundaries that recover

Three sections, each inside its own boundary. One is stable, one calls an endpoint that fails half the time, one can be made to throw while rendering. A failing section shows a fallback, retries with backoff twice, then offers a button; the rest of the page never notices. Reports are fingerprinted so the same failure is counted, not resent.
