Pattern 23 of 23: styling strategy

Tokens and layers

The whole site is styled from one set of custom properties. Colours are declared once with light-dark() and switch with the colour scheme. Cascade layers decide which rules win regardless of order or specificity. This is the floor every styling approach, from CSS Modules to Tailwind to CSS-in-JS, builds on.

Cascade layers

Both rules below target the same element. The "base" rule appears later in the stylesheet, but the layer order @layer theme, base; is reversed on purpose, so the theme wins.

Which layer painted me?
@layer base, theme;
@layer theme { .layered { background: var(--accent-soft); } }
@layer base  { .layered { background: var(--surface-2); } }   /* later in the file, lower in the order */
