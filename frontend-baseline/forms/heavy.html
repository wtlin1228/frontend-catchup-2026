What this page exercises

  • Constraint Validation API for messages, with novalidate added by script only.
  • Validation on blur, then live after a field was touched.
  • Submission via fetch with the same action the plain form uses.
  • Field errors returned by the server (400) rendered next to the inputs.
  • Draft kept in sessionStorage until it is sent.
  • A honeypot field instead of a captcha.
  • A file upload with progress via XMLHttpRequest, cancellable, referenced by id on submit.
