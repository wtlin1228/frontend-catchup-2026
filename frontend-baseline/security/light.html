Pattern 22 of 23: security hardening

A strict policy

This page carries a Content-Security-Policy that allows scripts only from this origin plus the hashes of its own inline scripts, which the build computes. The theme reader in the head is one of them: every framework with an inline bootstrap or an inline hydration script has the same problem to solve, with a nonce or a hash. Try the buttons and watch the violation log.
