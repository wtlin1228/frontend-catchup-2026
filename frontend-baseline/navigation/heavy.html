Pattern 19 of 23: platform navigation

Routes on real paths

A client-side router built on the Navigation API and URLPattern: real URLs under /navigation/app, interception with scroll and focus handling, cancellation through the event signal, a view transition per navigation, and the history entries list the API exposes. The server serves this shell for any URL under that prefix, so deep links and reloads work. Browsers without the API get full page loads from the same links.
